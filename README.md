# nicoloiacobone

Sito web personale di Nicolò Iacobone, disponibile in italiano e inglese.

Realizzato in HTML/CSS/JS puro (nessun build step) e hostato su [GitHub Pages](https://pages.github.com/).

## Funzionalità

- Selettore di lingua italiano / inglese

## Sviluppo

Nessuna build richiesta: aprire `index.html` nel browser, oppure servire la cartella con un server statico (es. `npx serve`).
